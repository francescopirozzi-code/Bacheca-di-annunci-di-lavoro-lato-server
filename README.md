# Bacheca di annunci di lavoro lato server

Lato Server dell'applicazione Bacheca di Annunci di Lavoro

## Come eseguire
1. Installa le dipendenze: `dart pub get`
2. Avvia il server: `dart run`

Il server sarà attivo sulla porta `8080` e raggiungibile dai dispositivi sulla stessa rete Wi-Fi tramite l'IP locale del PC.
